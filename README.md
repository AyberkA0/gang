# GANG

*Gang Avoids Nasty Git-merges*

A terminal version-control tool for Unity teams, built on top of git and GitHub.

GANG aims to make working on the same Unity project with friends less painful: scenes and prefabs that merge object by object, quick questions for the conflicts that are real, a shared view of who is changing what, locks for files and objects, and one setup that behaves the same on macOS, Windows and Linux.

## Status

Early development. Nothing is usable yet.
